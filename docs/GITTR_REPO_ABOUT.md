# gittr sidebar “About” text

Paste this into **Repository settings → Description** on [gittr.space](https://gittr.space) (gear icon next to About), then save/publish so relays store it on your kind `30617` event.

If you only update this file on GitHub, gittr will still show the README **## About** section in the sidebar when the Nostr description is the default `Repository: gittr-helper-tools` placeholder (gittr UI fallback).

---

**Developers and coding agents** building or extending **Nostr-native Git clients** (web apps, desktop tools, relays, bridges). This is not end-user documentation for gittr.space.

We publish **copy-pasteable modules** and **interop notes** from [gittr.space](https://gittr.space) production so you can implement NIPs (NIP-34, C0, 25, 51, 46, …), match network behaviour other clients already use, and grow features faster than reading the full gittr monorepo.

Start with [`docs/FOR_OTHER_CLIENTS.md`](./FOR_OTHER_CLIENTS.md) when porting snippets into your client.
